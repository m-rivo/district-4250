# Getting Started

## 1. Pocketbase server

### 1. Download Pocketbase for your operating system from https://pocketbase.io/docs/

### 2. Extract the pocketbase.exe from the downloaded ZIP file and put it in the district-4250\backend directory.

### 3. Start the server:

```bash
./pocketbase serve
```

### 4. Go to:

http://localhost:8090/\_/

## 2. Vite server

### 1. In the district-4250\frontend directory install dependencies:

```bash
npm i
```

### 2. Start the server:

```bash
npm run dev
```

### 3. Go to:

http://localhost:3000
